# Sim Atlas

An interactive, 30-day learning system for embodied simulation: robotics and physics fundamentals, engines and platforms, scene assets, robot learning, sim-to-real evaluation, and product value.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server 4173` from this directory and visit `http://127.0.0.1:4173/`. No build step or package installation is required.

## GitHub Pages

A GitHub Actions workflow deploys the repository root after pushes to `main`. GitHub Pages sites are public on the internet by default, including when the source repository is private, unless the owning GitHub Enterprise organization enables private site access control.

Study progress, quiz results, and notes remain in the current browser.
